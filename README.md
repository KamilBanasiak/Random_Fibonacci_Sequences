# Random\_Fibonacci\_Sequences

This repository contains my experiments with random Fibonacci sequences.

## Purpose

The goal of this project is to have fun experimenting with Fibonacci sequences using Python.

## Mathematical background

The Fibonacci sequence starts with 0 and 1. Each subsequent element is the sum of the two preceding elements.

The Random Fibonacci Sequences also start with 0 and 1. However, each subsequent element is calculated as the sum of two randomly selected elements that appear earlier in the sequence.

## Features

* Generate a Random Fibonacci Sequence
* Check whether a sequence is a Random Fibonacci Sequence
* Save data about a Random Fibonacci Sequence
* Extend a Random Fibonacci Sequence
* Calculate the sum of the elements in a Random Fibonacci Sequence
* Calculate the probability that the next element is m in a Random Fibonacci Sequence
* Calculate the number of Random Fibonacci Sequences with n elements
* Calculate the probability of generating a Random Fibonacci Sequence element by element
* Generate a list of Random Fibonacci Sequences whose elements sum to m
* Calculate the probability of generating the nth Random Fibonacci Sequence with a sum of m from a set of n-element Random Fibonacci Sequences
* Calculate the probability of generating the nth Random Fibonacci Sequence with a sum of m element by element
* Calculate the set of possible next elements
* Display a Random Fibonacci Sequence and its possible next elements
